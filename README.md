## What this is

Polaris is a set of 4,000 computer-generated characters built on Ethereum.
Every form is generated by the contract itself — no image servers, no metadata
hops, no host to switch off.

This repo is the whole thing:

- **The site** — a minimal static site (no build step) with the collection, the
  terms/privacy/cookies/credits, and the 3D printer.
- **The generator** — the LPC-based pipeline that composites the 4,000 forms
  from layered traits (clothes, eyes, eyebrows, hair, accessory) with
  independent skin tones and a separate head layer.
- **The 3D printer** — pick any form (or upload your own photo) and it becomes
  a 3D-printable medallion. A live isometric printer builds it on screen, and
  you download a binary STL to print on your own machine.

## The forms

4,000 tokens · 4,000 unique trait sets · 512 px PNGs · bust crops · animated
GIFs. Each one is composited from five trait groups onto a 48×29 character
plate, with 14 skin tones and 5 palettes. The full metadata and credits are in
`nft/`.

## The 3D printer

`/printer` is a self-contained print shop:

- **Pick a form** — 4,000 forms, reroll to browse more.
- **Watch it print** — a live, drag-to-turn, see-through isometric 3D printer
  (Colorfigures) lays down the medallion layer by layer, with labels for the
  hot end, nozzle, filament, print bed and more.
- **Download the STL** — the selected form becomes a ~50 mm medallion (2 mm
  base + relief), generated client-side as a binary STL.
- **Print your own photo** — any image becomes a relief medallion, the same
  way.
- **Already printed** — a gallery of finished medallions.

The STL generator is both client-side (in `printer.html`, zero dependencies)
and a standalone script (`tools/to_stl.py`) that produces byte-identical
output.

## Run it locally

```bash
git clone https://github.com/0xklen/polaris
cd polaris
python3 tools/serve.py            # -> http://127.0.0.1:4173/
```

Clean-URL router, no dependencies, Python 3 stdlib only. The site deploys
unchanged to Vercel.

## Repo layout

```
├── printer.html         the 3D printer hub (pick / print / upload / gallery)

├── terms / privacy / cookies / credits .html
├── assets/              styles, logos, favicons, print STLs
├── tools/               serve.py, to_stl.py, the LPC generator + compositing
├── nft/                 4000 PNGs, busts, metadata, credits (GIFs not tracked)

```
